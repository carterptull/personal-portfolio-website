# Security Policy

This portfolio site hasn't had a full code or security review yet, and there's no live
production domain deployed — so this is a placeholder policy rather than the result of a real
review. A more thorough SECURITY.md is planned once the site is deployed publicly.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a security vulnerability. Instead, use
GitHub's private vulnerability reporting for this repository:
[github.com/carterptull/personal-portfolio-website/security/advisories/new](https://github.com/carterptull/personal-portfolio-website/security/advisories/new).

Only the latest commit on `main` is supported — there are no maintained release branches yet.
