# Version

**Current version:** 0.1.0-beta

The version string lives in `package.json` (single source of truth); `src/lib/site.ts`
re-exports it as `SITE_VERSION` for display in the taskbar and Start menu. See
[CHANGELOG.md](CHANGELOG.md) for release history.

The `-beta` suffix drops to `1.0.0` once a custom domain is live.
